# Mouse Museum

Для публикации этого сайта по командам «выкати изменения», «залей на прод», «задеплой» и аналогичным обязательно прочитай и выполни [Как деплоить изменения на продакшн](skills/mouse-museum-deploy/SKILL.md).

Прод — https://mouse.museum/, GitHub — michael-pavlov/mouse-museum, публикация push в main через GitHub Actions / GitHub Pages. Команда деплоя разрешает commit, push, ожидание workflow и проверку прод-сайта без повторных разговорных подтверждений. Системные ограничения и обязательные инструментальные разрешения остаются в силе. Не публикуй обычные правки автоматически без команды на деплой.

## Дизайн

Не добавляй декоративные стрелки к ссылкам, кнопкам, подписям и другим элементам интерфейса. Пользователь явно попросил больше их нигде не использовать. Функциональные значки навигации и отправки не заменяй декоративными стрелками.
