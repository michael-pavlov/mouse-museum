# Обменный фонд

Одна модель/позиция — один JSON. В первоначальном импорте 15 записей из фильтра:

https://collectionerus.ru/collections/old-mice/?folder=public&sorting=0&obmennyi_fond=есть

Обычная HTML-страница содержит неотфильтрованный список: фильтр выполняется отдельным запросом. Для импорта получены результаты штатного `@filter/`, подтверждено отсутствие следующей страницы, а у каждой позиции отдельно проверено поле «Обменный фонд». Значение сохранено в `sourceStock`. Это снимок доступности на 27 октября 2026; дальнейшие изменения делаются здесь вручную.

- `quantity` — количество из исходной записи, например 1 или 2;
- `status: "available"` — доступно для обмена. После передачи всех экземпляров смените на `"exchanged"`;
- `catalogueSlug` — обязательный slug локального экспоната. Название и превью берутся из этой карточки, ссылки появляются в обе стороны;
- `source` — исходная карточка;
- `order` — порядок в списке;
- `id` — постоянный якорь, не менять после публикации.

Обменник не создаёт дополнительные экспонаты в основном каталоге и не меняет его счётчик. Фото может иллюстрировать модель из исходной карточки; состояние конкретного обменного экземпляра обсуждается в переписке. Кнопка «Обсудить обмен» открывает черновик письма с названием и ссылкой. Она не отправляет письмо автоматически.


Карточка обменника открывает страницу экспоната при клике на фото или название. В отличие от Wanted, фото здесь не открывает отдельный просмотр. Для увеличения фото откройте карточку и нажмите снимок в её галерее: у просмотра есть крестик и Escape.

Все 15 обменных позиций связаны с локальным каталогом. Для этого добавлены 13 недостающих карточек и по четыре фотографии — каталог теперь содержит 49 уникальных записей. Названия и превью не дублируются в JSON обменника: измените их в `content/mice`, и изменения автоматически отразятся в обменном фонде.
