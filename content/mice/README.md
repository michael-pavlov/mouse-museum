# Дополнительные поля карточки экспоната

У каждого экземпляра свой JSON. Следующие поля необязательны; пустые блоки на странице не выводятся.

```json
{
  "description": {
    "ru": "Свободный текст об экземпляре.\n\nВторой абзац.",
    "en": "A note about this mouse.\n\nAnother paragraph."
  },
  "externalLinks": [
    {
      "url": "https://example.com/manual.pdf",
      "title": {"ru": "Инструкция · PDF", "en": "Manual · PDF"}
    }
  ],
  "channelPost": "https://t.me/old_mice_and_hw/68",
  "whereToSee": {
    "ru": "Краснохолмская",
    "en": "Krasnokholmskaya Gallery"
  }
}
```

- `description` — свободный текст под галереей, с сохранением абзацев и переносов. Это обычный текст, HTML не исполняется. Для журнала остаются отдельные Markdown-файлы.
- `externalLinks` — каталоги, инструкции, видео, публикации на других сайтах. Заголовки нужны на обоих языках. Ссылки открываются в новой вкладке.
- `channelPost` — исходный пост в Telegram для обратной совместимости. Не заменяет связи с нашим журналом. Допускается строка или массив полных ссылок на несколько сообщений.
- `whereToSee` — подпись «Где посмотреть» в характеристиках. Значение показывается как дано; адрес или условия посещения не придумываются.

Если `channelPost` отсутствует, сборщик извлекает полную ссылку из `sourceProperties["Пост в канале"]`. Повторные сокращённые подписи исходного сайта игнорируются. Если `whereToSee` отсутствует, используется прежнее `sourceProperties["Где посмотреть"]`; известные подписи переведены для EN. Чтобы скрыть старое значение, задайте `channelPost: ""` или пустые `whereToSee.en` и `whereToSee.ru` явно. Учтите, что исторические значения вроде «Ближний» и «Демо Витрина» — исходные ярлыки, а не новые публичные адреса.

Уже заполнены примеры:

- `penny-giles-m3-100-for-acorn-a500-191.json` — описание, Acorn A500, Telegram №68, Краснохолмская;
- `tandy-color-mouse.json` — YouTube, два каталога, инструкция PDF, Демо Витрина.

Связи с публикациями локального журнала задаются в JSON самих публикаций, в `relatedItems`; повторять их здесь не нужно.

Проверки после сборки: `python3 scripts/test_specimen_content.py` и `python3 scripts/check.py`.


«Где посмотреть» включено в фильтры каталога. Значения производителя, года, технологии, интерфейса, места просмотра и СССР в карточке кликабельны: открывают каталог с соответствующим параметром URL. Для места используется общий ключ `location`, одинаковый в EN/RU, поэтому переключение языка сохраняет выбор. Пустые места доступны через «Не указано».

## Полный набор фотографий

После полной сверки каждое фото содержит:

- `file` — оптимизированная версия для страницы;
- `thumbnail` — маленькая миниатюра в галерее;
- `original` — путь к файлу оригинала без перекодирования;
- `originalSource` — URL оригинала на исходном сайте;
- `originalFilename`, `originalWidth`, `originalHeight`, `originalBytes`, `sha256` — сведения для проверки оригинала;
- `width`, `height` — размер WebP для просмотра;
- `caption` — исходная подпись, если есть.

Обычная сборка ничего не скачивает: все файлы уже локальные. `boardManufacturer` хранит производителя платы EN/RU, если он задан в источнике. `sourceSync` содержит дату получения и исходное количество фотографий; полный снимок данных — в `data/source/collectionerus`.

## Год и исходные изображения

`year` — целое число или `null`; неизвестный год не заменяется предположением. В фильтре есть пункт «Не указано», в карточке выводится прочерк.

У фотографий сохраняются исходный URL, разрешение, размер и SHA-256. Файлы в `originals/` не перекодированы. Если оригинал недоступен и сохранено публичное превью, задаётся `originalAvailable: false`, фактический `downloadSource` и причина `sourceOriginalError`; такой файл хранится в `source-images/` и подписывается «Изображение источника». На 27 октября 2026 такое исключение одно: ID 53, фото 1.
