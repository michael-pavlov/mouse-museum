# Wanted — искомые мыши

Одна позиция — один JSON. Снимки находятся в `assets/wanted/<id>/`. Поля:

- `id` — постоянный якорь на странице, не менять после публикации;
- `reference` — короткий номер, который подставляется в письмо;
- `title.en` / `title.ru` — название, если модель точно известна; пустое значение допустимо;
- `image` — полная фотография, `thumbnail` — превью;
- `order` — порядок показа;
- `source` — исходная страница фотографии;
- `status: "wanted"` — показывать. Когда мышь найдена, измените на `"acquired"`.

Названия из файлов вроде `photo-2024...` не выданы за названия моделей: в первом импорте названия оставлены пустыми. У каждой карточки есть собственная кнопка «У меня есть такая», которая открывает письмо с номером и ссылкой на изображение. При сборке с SITE_URL письмо содержит постоянную ссылку на карточку Wanted вместо ссылки на источник.

Импорт из https://ibb.co/album/jynZDw выполнен 27 октября 2026. Счётчик альбома показывает 28 изображений, но публичная HTML-выдача и публичная JSON-подгрузка возвращают 25 уникальных изображений, включая запрос второй страницы и обратного порядка. Перенесены все 25 доступных, отсутствующие три не подменены и не придуманы. Фото сохранены локально; сайт не зависит от ImgBB при просмотре.

Файл `scripts/import_wanted.py` позволяет повторить импорт из кешированной публичной выборки и скачанных изображений. Повторный импорт не перезаписывает ручные изменения карточек. Автоматической синхронизации с альбомом нет.
