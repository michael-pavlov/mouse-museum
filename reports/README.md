# Сверка и полный перенос существующих карточек

`collectionerus-sync.json` и `collectionerus-sync.md` создаются после завершения переноса. Для каждого экспоната показываются количество фотографий до/после, внешние ссылки и незаполненные поля источника.

В `data/source/collectionerus/<ID>.json` хранится структурированный снимок исходной карточки: заголовок, исходное HTML-описание, извлечённый текст, все параметры и их ссылки, весь порядок фотографий, URL оригиналов и подписи. Изображения отдельно в `assets/photos/<slug>/originals/`. Это исходные файлы без перекодирования; SHA-256 и размер записаны у каждой фотографии в JSON экземпляра.

Оригиналы, WebP для просмотра (до 2400 px), маленькие галерейные миниатюры и каталожное превью — разные файлы. Ссылку на оригинал и его разрешение можно найти под основной фотографией. Увеличенный просмотр использует оригинал, обычная страница — WebP.

Пустое описание или параметр не заполняются догадками. Они отмечаются в отчёте как отсутствующие в источнике. Исторические характеристики не переосмысляются; существующие замечания о спорных значениях сохраняются.

Оно лежит в `source-images/`, помечено `originalAvailable: false` и не называется оригиналом в интерфейсе. Настройка исключения — `data/source/download-overrides.json`.

Для полного обнаружения каталога: скачать все страницы списка, затем выполнить `python3 scripts/discover_catalogue.py listing-1.html listing-2.html listing-3.html listing-4.html --output index.json`. Скрипт проверяет пагинацию, дубликаты и итоговое количество. Затем `python3 scripts/import_catalogue.py index.json --cache <cache>` создаёт промежуточные JSON только для новых карточек; после этого скачать их HTML и продолжить обычный процесс ниже.

## Воспроизведение

Импорт требует `python3 -m pip install -r requirements-import.txt`; для обычной сборки сайта этот файл не нужен.

1. Скачать HTML всех имеющихся источников в `<cache>/pages/<ID>.html`. Список берётся из `source` в `content/mice/*.json` и из индекса новых экземпляров.
2. `python3 scripts/sync_collectionerus.py plan --cache <cache>` — подготовить план и `<cache>/originals.conf` для curl. Полностью декодируемые уже скачанные файлы пропускаются.
3. Скачать файлы из конфига curl, при обрывах поддерживается `--continue-at -`. Дождаться завершения запросов, затем проверить все файлы.
4. `python3 scripts/sync_collectionerus.py apply --cache <cache>` — проверить все оригиналы и разрешения, скопировать исходные байты и создать отдельные превью, обновить JSON и отчёт.
5. Собрать сайт и запустить проверки:

```bash
python3 scripts/build.py
python3 scripts/check.py
python3 scripts/test_source_sync.py
python3 scripts/test_specimen_content.py
python3 scripts/test_journal.py
python3 scripts/test_wanted.py
node scripts/test_catalog.cjs
node scripts/test_photo_viewer.cjs
```

`apply` сохраняет ID, slug, порядок коллекционера, существующие примечания и связи с журналом. Основные характеристики, описание, ссылки, Telegram, место просмотра и количество обменных экземпляров обновляет по снимку источника. Перед повторной синхронизацией учитывайте, что эти поля могут содержать ваши более новые ручные правки.
