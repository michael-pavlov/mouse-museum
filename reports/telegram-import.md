## Границы архива

- Это архив публичной ленты, а не авторизованный экспорт аккаунта. Удалённые и непубличные сообщения восстановить из неё нельзя.
- Комментарии и вложения группы обсуждения не входят в публичную ленту. Продолжение №54 и документ, упомянутый в №134, здесь не представлены; в статьях есть пояснение и ссылка на источник. У №201 также сохранена пометка об обсуждении в Telegram.
- Опрос №173 сохранён как вопрос с пятью вариантами ответа. Голосование не имитируется, результаты не обновляются.
- Исторические утверждения и авторские оговорки сохранены. Перевод не является отдельной проверкой изложенных фактов.
- Все анонсы сохраняют исходный текст и пометку о прошедшем событии.

## Файлы

- `data/source/telegram/*.html` — исходные страницы публичной ленты.
- `data/source/telegram/posts.json` — разобранные записи, опрос и URL медиа.
- `data/source/telegram/translations.md` — английские тексты новых статей и двуязычные заголовки.
- `data/source/telegram/excerpts.json` — анонсы новых статей на двух языках.
- `data/source/telegram/media-manifest.json` — размеры и SHA-256 скачанных оригиналов и видео.
- `data/source/telegram/media-errors.json` — ошибки загрузки; при этом переносе список пуст.
- `reports/telegram-import.json` — соответствие Telegram ID статьям и связи с каталогом.

## Повторение переноса

Зависимости импорта: `python3 -m pip install -r requirements-import.txt`. Нужен также `curl`. Для обычной сборки достаточно прежнего `requirements.txt`; сайт при просмотре не обращается к Telegram.

```bash
python3 scripts/fetch_telegram.py --refresh
# Для новых Telegram ID дополнить translations.md и excerpts.json.
python3 scripts/import_telegram.py
python3 scripts/build.py
python3 scripts/check.py
python3 scripts/test_journal.py
python3 scripts/test_telegram_import.py
```

Без `--refresh` загрузчик повторно использует сохранённые HTML и локальные медиа. Если не достигнута первая запись канала, загрузчик отказывается заменять полный архив неполной выборкой. Все фотографии декодируются, оригиналы и видео проверяются по SHA-256.

`import_telegram.py` повторно создаёт только автоматически импортированные статьи `telegram-*`. Ручные изменения этих статей следует переносить и в исходные переводы/анонсы, иначе повторный импорт их перезапишет. Три первоначальные статьи не перезаписываются. После обычного редактирования Markdown запускать импорт не требуется.
